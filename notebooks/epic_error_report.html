Как определены группы

N = число стартов (позиций со счётом > 0, среди оцениваемых). Берём N позиций с наибольшим предсказанием («верхние N»). TP: старт попал в верхние N. FN: старт вне верхних N (пропуск). FP: позиция из верхних N без старта (ложное срабатывание). BG: случайные оцениваемые позиции без старта и вне верхних N. При допуске ±k старт считается найденным, если в верхних N есть позиция в пределах k нт (фильтр по вектору позиций; на границах интервалов возможна небольшая утечка). Для признаков по последовательности берём случайные выборки до 20 000 позиций на группу; окно ±100 нт в направлении цепи.

    1. Допуск по позиции: сколько пропусков — это промах на пару нуклеотидов

    Метод. Для каждого k ∈ {0,1,2,5,10,20}: recall = доля стартов, рядом с которыми (±k) есть позиция из верхних N; precision = доля верхних N, рядом с которыми есть старт. Все оцениваемые позиции, без подвыборки.

    Код

    2. Пропуски зависят от силы старта

    Метод. Старты делятся на бины по суммарному счёту реплик. В каждом бине доля пропущенных = 1 − (найдено)/(стартов), строго (k=0) и с допуском ±5 нт. n у каждого столбца: число стартов в бине (подсказка при наведении). Без подвыборки.

    4. Кривые precision–recall

    Метод. Все старты + случайные 2 млн не-стартов с весом (число негативов / 2 млн); позиции сортируются по предсказанию, считаются взвешенные TP и FP. Показано 400 точек. Горизонтальные линии: доля стартов среди оцениваемых позиций (случайный уровень). AUPRC здесь строгий, по позициям, поэтому ниже официального.
