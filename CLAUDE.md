# Правила для этого репозитория

## Сабмиты EPIC
- К **каждому** файлу сабмита писать описание и добавлять запись в `SUBMISSIONS.md` (новые сверху, после строки `---`). В записи:
  дата · вид · краткое название; путь к файлу (Kaggle-ноутбук → Output), ветка и коммит;
  модель (из чего состоит, на каких видах обучена, сиды, вес смеси, alpha);
  оценка на report (AUPRC, Spearman) рядом с базовой моделью; проверки файла;
  поле «Лидерборд» (заполнить после отправки); короткий текст на английском для формы сабмита.
- Теги для формы сабмита (выбрать из списка сайта, можно дописать свои):
  Architecture: CNN / RNN / Transformer / Ensemble / Custom; Stage: Baseline / Finetune / Debug; Data: Augmented / Raw / Subset.
  `Finetune` — только если дообучали предобученную модель (Evo2, AlphaGenome и т.п.); `Subset` — если обучали на части данных;
  `Augmented` — если добавляли аугментации сверх обратно-комплементарной цепи.
- Метрики report считать с поправкой на размер теста (`rank_power(..., n_ref=...)` в v3), иначе они не сравнимы с лидербордом.
- Внешние данные запрещены правилами; предобученные модели разрешены, но в описании называть модель и версию.

- Готовые файлы сабмитов выкладывать новой версией датасета `ivanmitochondrion/epic-predictions` (аккаунт `k13polinaa` — редактор),
  в папку `submissions/` с суффиксом `.bin` (`<вид>.predictions.<модель>.alpha<α>.txt.gz.bin`): без суффикса Kaggle сам распаковывает `.gz`.
  Перед отправкой на сайт суффикс `.bin` убрать. Версия датасета заменяет все файлы — прошлые файлы, которые нужны, загружать снова.
